游戏介绍

《模拟人生・微力版》—— 一个用 Python 写的 3D 超市经营游戏。玩家在一个 3D 小镇里自由走动，经营一家超市赚钱。

🎮 能玩什么

🏃 3D 探索 —— 小人在小镇上走（马路、人行道、银行、超市、树），有碰撞箱、跳跃、走路动画，还能切女孩角色。

🏪 超市经营（核心玩法） —— 用笔记本电脑进货 → 摆上货架 → 给商品标价 / 改价 → 顾客进店购买 → 收银台收银。

💰 找零小游戏 —— 收银时要算找零（老按钮游戏迁移过来的）。

📱 手机系统 —— 按 P 键打开手机，里面能看到超市全部数据（库存、营业额、统计表等），进货、改价、查数据都搬进了手机。

🏦 银行模块 —— 同步银行卡账户，ATM 取存钱。

🛠️ 怎么做的

引擎：Ursina / Panda3D（Python 3D 引擎）

建模：Blender（银行、超市、小人、顾客都是建模出来的，顾客还会走路）

启动器：tkinter 界面，带激活码 + 时间卡授权系统（机器码绑定）

打包：3D 用 ursina.build 打包，启动器用 Nuitka 打包成 exe，玩家只双击一个 启动游戏.exe 就能玩

更新：启动时对比 Gitee 上的版本号，有新版就引导玩家去网盘下载

📌 当前版本：v3.0.0（银行核心）
